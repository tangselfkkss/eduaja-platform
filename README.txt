EDUAJA PRO - Learning Platform Demo
===================================

Fitur:
- Program Bahasa dan mapel nasional SD/SMP/SMA/SMK.
- Form pendaftaran siswa dengan pilihan jenjang + mapel yang sinkron.
- Username/password otomatis setelah pendaftaran.
- Form lowongan guru untuk semua jenjang dan program Bahasa.
- Upload field KTP, foto, ijazah, SKCK, rekening bank.
- Jadwal Senin-Jumat, sesi Pagi/Siang, 2 jam.
- Ruang belajar dan absensi online demo.
- Admin Studio tanpa edit source code: pages, pendaftar, guru, jadwal, pengaturan.
- Logo EduAja, logo CV. 8 Media Nusantara, dan QR pembayaran.

PENTING UNTUK PRODUKSI
Versi ini adalah prototipe frontend yang menyimpan data di localStorage browser. File upload belum dikirim ke server dan autentikasi belum aman untuk produksi. Untuk website online nyata, sambungkan backend/database, object storage untuk dokumen, autentikasi server-side, hashing password, role-based access, audit log, dan HTTPS.
